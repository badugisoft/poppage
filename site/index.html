Essential Features, Zero Bloat

Custom Menu Bar Icons

Fetch website favicons automatically, display custom text, or use your own image with macOS template mode support.

Navigation & New Window Policies

Decide per page whether links stay in the popover, open in your default browser, or stay locked to the pinned URL.

Custom HTTP Headers

Attach custom HTTP/HTTPS request headers and User-Agent overrides per page—ideal for internal tools and mobile views.

Adaptive Toolbar & Overlay

Bottom toolbar automatically adapts to webpage background colors, with optional overlay mode and adjustable opacity.

Persistent Size, Zoom & State

Keep login sessions and scroll positions alive across popover closes, and remember resized dimensions and zoom levels.

Multilingual & JSON Backup

Switch between 8 languages on the fly and export or import all pages, custom icons, and preferences as a single JSON file.
