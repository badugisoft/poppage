# AGENTS.md

## Project Overview

PopPage is a Swift menu bar application for macOS 14+, built with a Swift Package Manager (`Package.swift`) executable target and an `.app` bundle assembly script (`scripts/build-app.sh`). Built 100% with Antigravity.

## Directory & File Roles

- `Package.swift`: Defines the `PopPage` executable target (`swift-tools-version: 6.0`, Swift 5 language mode, macOS 14+)
- `Resources/Info.plist`: Menu bar app bundle metadata (`LSUIElement = true`, ATS configuration, `CFBundleIconFile = AppIcon`, `CFBundleDevelopmentRegion = en`, `CFBundleLocalizations = [en, ko, zh-Hans, ja, es, de, fr, tlh]`)
- `Resources/AppIcon.icns`: Application icon bundle generated by `scripts/generate-icon.swift`
- `Resources/Localization/{en,ko,zh-Hans,ja,es,de,fr,tlh}.lproj/Localizable.strings`: Localized UI strings for English (default), Korean, Simplified Chinese, Japanese, Spanish, German, French, and Klingon
- `scripts/build-app.sh`, `scripts/generate-icon.swift`, `scripts/update-screenshots.sh`, `Makefile`: Release build, app icon generation, automated mock-data screenshot capture, `build/PopPage.app` assembly/signing, and `install`/`uninstall`/`lint`/`clean` targets
- `.github/workflows/release.yml`, `.github/workflows/pages.yml`: Tag-triggered signed/notarized `.dmg` & `.zip` release workflow (with `CHANGELOG.md` notes + compare link) and `main`-triggered GitHub Pages deployment
- `.agents/skills/{commit-and-push,release,update-screenshots}/SKILL.md`: Project skills for commit/push, changelog-based release, and screenshot updates
- `site/{index.html,styles.css,i18n.js}`: Multilingual static landing page for GitHub Pages (with Cloudflare Web Analytics)
- `Sources/PopPage/PopPageApp.swift`: `@main` AppKit entry point (`NSApplication` direct launch and main menu setup) — SwiftUI `App` lifecycle is avoided because it opens an empty `Settings` window
- `Sources/PopPage/AppDelegate.swift`: Management window lifecycle using `NSHostingController`
- `Sources/PopPage/Models/PageItem.swift`: Per-page configuration model (`Codable`, defaults for missing keys) and `HTTPHeader` model
- `Sources/PopPage/Models/PageStore.swift`: `pages.json` persistence and CRUD operations
- `Sources/PopPage/Services/ImageStore.swift`: Icon/favicon file storage and menu bar resizing
- `Sources/PopPage/Services/FaviconFetcher.swift`: Favicon lookup via HTML `<link>` → `/favicon.ico` → Google S2 (forwards custom headers only to same-host requests)
- `Sources/PopPage/Services/LaunchAtLogin.swift`: Launch at Login status and registration via `SMAppService.mainApp`
- `Sources/PopPage/Services/L10n.swift`: Localization helper (`tr`, `format`) and `LocalizationManager` for in-app language switching (`System Default`, `en`, `ko`, `zh-Hans`, `ja`, `es`, `de`, `fr`, `tlh`)
- `Sources/PopPage/Services/SettingsTransfer.swift`: JSON backup export/import (`SettingsBackup`) bundling pages, custom icons, and app language
- `Sources/PopPage/StatusBar/StatusBarManager.swift`, `PageStatusItem.swift`: `NSStatusItem` and `NSPopover` lifecycle management
- `Sources/PopPage/Popover/PopoverContentViewController.swift`, `WebViewCoordinator.swift`: Bottom toolbar (standard/overlay modes), `WKWebView`, resize grip, navigation/new-window policies
- `Sources/PopPage/UI/ManagerView.swift`, `PageEditorView.swift`, `AppSettingsView.swift`, `IconPreview.swift`: Page list/editor and bottom-left Settings tab UI
- `CHANGELOG.md`, `README.md`, `docs/README.{ko,zh-Hans,ja,es,de,fr,tlh}.md`, `docs/images/*.png`: Changelog, English/localized documentation, and UI screenshots

## Architecture Notes

- **Persistent WebView State**: `PageStatusItem` owns the `WKWebView` so login and scroll state persist across popover closes. Pages reload only when the normalized URL changes.
- **Navigation Policy Scope**: `navigationPolicy` applies only to main-frame navigations triggered by user clicks (`.linkActivated`) or form submissions (`.formSubmitted`); initial loads, redirects, back/forward, and reloads are always allowed.
- **Custom HTTP Headers**: `PageItem.customHeaders` applies to `http`/`https` requests via `makeURLRequest(for:)`, main-frame GET interception in `WebViewCoordinator` (with single-shot `pendingHeaderInjectionURL` guard), `webView.customUserAgent` override for `User-Agent`, and same-host favicon requests in `FaviconFetcher`.
- **Settings Export/Import**: `SettingsTransfer` exports and imports `SettingsBackup` JSON containing `pages`, `appLanguage`, and base64-encoded `customIcons`, sanitizing filenames with `lastPathComponent` on restore.
- **Preventing `.transient` Popover Reopen**: With `NSPopover.behavior = .transient`, clicking the status bar button may close the popover before firing the button action. `popoverDidClose` records the close timestamp and ignores reopens within 0.3 seconds.
- **Bottom Toolbar Background**: The toolbar sits at the bottom of the webview, observes `themeColor` → `underPageBackgroundColor` via KVO, and applies `.aqua` or `.darkAqua` appearance based on sRGB luminance. When `toolbarOverlay` is enabled, `toolbarOverlayOpacity` (0.0–1.0) controls the background color alpha.
- **Default vs. Saved (`saved*`) Size & Zoom**: `width`/`height`/`defaultZoom` store the original defaults, while user-resized/zoomed values are stored separately in `savedWidth`/`savedHeight`/`savedZoom`. When `toolbarOverlay` is `false`, the toolbar height (31pt) is added to the popover height to preserve the webpage area; when `true`, the total size includes the toolbar. Opening the popover applies `effectiveSize`/`effectiveZoom`, reverting to defaults when persistence is disabled.
- **Editor `.id(selectedID)`**: `ManagerView` attaches `.id(selectedID)` to `PageEditorView` so switching pages does not trigger `.onChange` handlers and inadvertently clear `saved*` values.
- **Localization**: Default language is English (`en`), with `ko`, `zh-Hans`, `ja`, `es`, `de`, `fr`, and `tlh` supported via `Localizable.strings` and `L10n`. `LocalizationManager` persists the user's choice (`system` or language code) in `UserDefaults`, resolves the active `.lproj` bundle at runtime, and broadcasts `.appLanguageDidChange` so SwiftUI views, the main menu, and toolbar tooltips update immediately without relaunching. All developer-facing docs (`AGENTS.md`) and code comments are written in English.
- **Popover Keyboard Shortcuts**: `PopoverContentViewController` registers a local `NSEvent` keyDown monitor (scoped to `event.window === view.window`) supporting `⌘+`/`⌘-`/`⌘0` (zoom) and `⌘[`/`⌘]`/`⌘R` (navigation/reload) when the page's `enableKeyboardShortcuts` is enabled.
